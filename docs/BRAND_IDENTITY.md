# Luma Brand Identity

版本：0.1.0 Spark  
状态：初稿，随产品迭代

## 1. 品牌核心

**Luma**

词源联想：Luminescence（发光）、Luminous（明亮）。

理念：让打印过程变得清晰、直观、优雅。

宣传语：**Your Printing, in Sight.**

中文：让每一次打印，都清晰可见。

品牌气质：光、克制、精确、可靠、有创造力。

## 2. 品牌边界

可以：

- 光环、进度环、光线、层纹、几何化 L。
- 深色底上的柔和蓝光。
- 大量留白与清晰层级。

避免：

- 机械齿轮、传统打印机剪影。
- 廉价蓝紫渐变、过度发光。
- 复制 Apple、Bambu Lab 的 Logo 或界面资产。

## 4. 字体

- 中文：Microsoft YaHei UI（当前）
- 西文/数字：随系统字体回退
- 正式版考虑内置一款开源字体，避免系统差异。

字号层级（逻辑像素）：

| 用途 | 字号 | 字重 |
|---|---|---|
| 页面主标题 | 28 | 700 |
| 卡片标题 / 任务名 | 24–26 | 600 |
| 进度大数字 | 46 | 700 |
| 正文 | 14 | 400–600 |
| 辅助 | 11–12 | 400 |
| 标签 / 全大写 | 9–10 | 600，字距 1.6 |

原则：不超过 3 级同屏竞争；数字使用等宽感强的展示方式（后续可引入 tabular figures）。

## 5. 间距

基础单位 4px。

常用：4 / 8 / 12 / 16 / 18 / 24 / 26 / 32。

- 页面内边距：26
- 卡片内边距：16–18
- 卡片间距：14–18
- 侧栏项内边距：12–16

## 6. 圆角

| 元素 | 圆角 |
|---|---|
| 大卡片 | 24 |
| 普通卡片 | 18 |
| 列表项 | 14 |
| 按钮 / 胶囊 | 12–16 |
| 圆点 | 50% |

禁止所有元素统一大圆角；层级越高，圆角越大。

## 7. 阴影与材质

- 深色主题以边框和背景层级为主，少用阴影。
- 浅色主题可使用非常轻的阴影（后续调参）。
- 半透明材质仅用于局部强调，不做大面积毛玻璃。

## 8. 动效

- 进度变化：700ms，ease-out。
- 主题切换：颜色即时或 150–200ms 过渡。
- 悬停：120–160ms。
- 禁止弹跳、过度缩放、长时间循环动画。
- 动画不得阻塞数据更新。

## 9. 图标

- 线性、1.5–2px 描边、圆角端点。
- 同一页面不混用多种图标风格。
- 优先自绘少量图标，避免风格不统一。

## 10. 数据可视化

- 主视觉是当前任务与进度环。
- 温度用数值 + 目标值，不用复杂仪表盘。
- 状态用颜色 + 文字双重编码，不能只靠颜色。
- 数字对齐，单位弱化。

## 11. Logo 探索

方向优先级：

1. 光环 / 进度环与字母 L 的结合。
2. 一束光穿过层纹。
3. 几何化 L 与圆点。

要求：

- 16px 下仍可识别。
- 单色可用。
- 深色底与浅色底都成立。
- 不依赖渐变。

## 12. First Light 启动体验

1.0.0 启动画面建议：

1. 深色背景。
2. 一束柔和光线出现。
3. 光线形成 Luma 标志与进度环。
4. 显示 `FIRST LIGHT`。
5. 进入主界面。

时长控制在 1.5 秒内，可跳过，不阻塞数据加载。
