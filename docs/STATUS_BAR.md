# 顶部/底部状态条（Status Bar）

吸附在屏幕工作区边缘的细条，用来在不开主窗口时查看打印机状态。

## 行为

| 项 | 值 |
| --- | --- |
| 停靠 | 屏幕顶部、底部，或 Windows 任务栏内部 |
| 位置 | 主屏或鼠标所在屏；水平可靠左 / 居中 / 靠右 |
| 大小 | 自动宽度（按内容，最大 1400 px）或手动 280–1400 px；高度 24–64 px，缩放 80–160% |
| 层级 | 置顶（always-on-top） |
| 任务栏 | 不显示（`WS_EX_TOOLWINDOW`，并清除 `WS_EX_APPWINDOW`） |
| 关闭 | 忽略关闭请求（`KeepWindowShown`），不会因任务栏/Alt+F4 误关 |
| 焦点 | 不抢（`WS_EX_NOACTIVATE`） |
| 鼠标 | **始终点击穿透**（`WS_EX_TRANSPARENT`），点击落到状态条下方窗口 |
| 悬停 | 鼠标进入状态条矩形后约 120ms 淡出并隐藏；离开后淡入恢复 |
| 过渡 | 自动宽度分步过渡；进度线、开关、分段控件与悬停状态均带短动画 |
| 全屏 | 可选：前台窗口全屏或最大化时自动收起 |
| 开关 | 托盘菜单「顶部状态条」可勾选 |
| 深/浅色 | 跟随主窗口主题 |
| 工具栏 | 可显示时钟、秒、日期、电池，并与打印机内容一起参与自动宽度 |

状态条本身不接收点击，因此设置入口是：

- 托盘菜单「状态条设置…」；
- 主窗口左侧「设置」；
- 托盘菜单「显示 Luma」。

启动参数 `--no-bar` 可让状态条默认不显示（之后仍可用托盘菜单打开）；
`--taskbar` 可临时用任务栏模式启动，不写入配置文件。

## 设置页（主界面左侧「设置」）

页面结构照 ClassIsland 的设置页：按「常规 / 位置与尺寸 / 外观 / 内容 / 交互 / 关于」
分组，每组是圆角卡片，卡片内每行是「标题 + 说明 + 右侧控件」。

| 项 | 控件 | 范围 | 默认 |
| --- | --- | --- | --- |
| 显示状态条 | 开关 | 开/关 | 关 |
| 屏幕 | 分段控件 | 主屏 / 鼠标所在 | 主屏 |
| 停靠 | 分段控件 | 顶部 / 底部 / 任务栏 | 顶部 |
| 对齐 | 分段控件 | 靠左 / 居中 / 靠右；任务栏模式自动贴近图标 | 居中 |
| 距边缘 | 滑块 | 0–64 px，步进 2 | 0 px |
| 自动宽度 | 开关 | 开/关 | 开 |
| 手动宽度 | 滑块 | 280–1400 px，步进 20；自动宽度关闭时生效 | 760 px |
| 高度 | 滑块 | 24–64 px，步进 1；高缩放会自动抬高最小值 | 40 px |
| 缩放 | 滑块 | 80–160%，步进 5% | 100% |
| 圆角 | 滑块 | 0–32 px，步进 1 | 10 px |
| 不透明度 | 滑块 | 20–100%，步进 5% | 85% |
| 品牌 / 设备名 / 状态 / 进度 / 剩余时间 / 进度线 | 开关 | 开/关 | 全开 |
| 智能排序 | 开关 | 异常、暂停、打印中优先 | 开 |
| 最多显示 | 分段控件 | 1–5 台 | 3 台 |
| 鼠标穿透 | 固定值 | 始终开启 | 开 |
| 悬停时隐藏 | 开关 | 开/关 | 开 |
| 全屏时隐藏 | 开关 | 开/关 | 关 |
| 时钟 | 开关 | 开/关 | 开 |
| 显示秒 | 开关 | 开/关；时钟关闭时置灰 | 关 |
| 日期 | 开关 | 开/关 | 关 |
| 电池 | 开关 | 开/关；无电池设备自动隐藏 | 关 |
| 自定义文本 | 输入框 | 最多 48 个字符 | 空 |

改动即时写入 `%APPDATA%\Luma\settings.json` 的 `bar` 字段并立刻应用。
「恢复默认」可一键回到上表默认值。

底部停靠使用显示器工作区，会自动避开 Windows 任务栏和其中的图标；
状态条本身不会占用任务栏按钮。

「任务栏」模式会用 UI Automation 读取任务栏按钮矩形，选择最大的空白区放入状态条；
图标增减或位置变化后约 1.2s 重新贴合。空间不足时会自动减少同时显示的打印机数量，
其余设备显示为 `+N`。状态条会贴紧图标区，避免与图标之间出现大片空白。
前台应用进入全屏时任务栏模式会自动隐藏，退出全屏后恢复。

## 显示内容

- 左侧：应用图标 + `Luma`（可关闭）
- 工具栏：时钟 `HH:mm` / `HH:mm:ss`、日期 `MM-dd 周X`、电池百分比与充电图标、
  用户自定义文本
- 每台打印机：状态点 + 名称 + 状态 + 进度百分比 + 剩余时间
- 每台打印机下方 2px 进度线
- 超过「最多显示」数量时显示 `+N`
- 没有设备数据时显示「未连接」

## 实现

- Slint 组件：`crates/luma-desktop/ui/main.slint` 的 `StatusBarWindow`
- 窗口定位、Win32 样式与悬停控制：`crates/luma-desktop/src/status_bar.rs`
  - `MonitorFromPoint` / `GetMonitorInfoW` 取目标显示器工作区
  - `GetDpiForMonitor` 计算目标屏缩放，避免跨屏 DPI 错位
  - 窗口样式追加
    `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE | WS_EX_LAYERED | WS_EX_TRANSPARENT`
  - 悬停检测用 33ms 轮询 `GetCursorPos` + `GetWindowRect`；窗口隐藏后矩形仍保留，
    因此不会出现“隐藏→立刻恢复”的闪烁
  - 120ms 淡入淡出用 `SetLayeredWindowAttributes` 分步修改 alpha，
    完成后用 `SW_HIDE` / `SW_SHOWNOACTIVATE` 隐藏或恢复
  - 自动宽度按当前可见设备、各类文本和内容开关在 Rust 侧测量，限制在
    280–1400 px 且不超过当前工作区；内容变化后由同一 33ms 轮询分步过渡到新宽度
  - `GetForegroundWindow` + `IsZoomed` 检测全屏/最大化前台窗口，并排除本进程
  - 任务栏模式在后台线程通过 UI Automation 枚举任务栏按钮，合并占用区间后选最大空白槽位；
    `Shell_TrayWnd` 为竖向、自动隐藏、副屏或空白不足时回退到底部贴边
  - 任务栏模式下会按槽位宽度自动减少可见打印机数量，避免所有文本一起被压缩
  - 定时重新断言 `HWND_TOPMOST`，防止任务栏重绘后覆盖状态条
  - 时钟/日期用 `GetLocalTime` 每秒刷新；电池用 `GetSystemPowerStatus`
    每 30 秒刷新，无电池或未知电量时自动隐藏
  - 自动宽度同时计算品牌、工具栏组件、分隔线与 `+N` 的宽度
  - Slint 根元素的 `window-width/window-height` 与原生窗口同步，避免内容按
    初始 560px 宽度布局而被裁切
  - 缩放较高时自动抬高最小高度，确保文字、图标与进度线不会被上下裁切
- 数据：`runtime::push_snapshot` 在更新主窗口时同步更新状态条；智能排序在运行时完成

## 已知限制

1. **状态条不可点击**。这是“始终穿透”的代价；设置请从托盘菜单或主界面进入。
2. **悬停检测有约 33ms 轮询间隔**。鼠标快速擦过时可能只触发淡出、不会完全隐藏。
3. **会盖住最大化窗口顶部**。鼠标移入时状态条会淡出，让出下方内容；
   不想保留这条行为可用设置关闭「悬停时隐藏」或从托盘关闭状态条。
4. **选屏只在应用配置时计算**。选择「鼠标所在」后，之后移动鼠标到其他屏幕不会自动搬迁；
   重新进入设置页修改任意状态条选项即可重新定位。
5. **不处理全屏独占游戏**。置顶窗口在独占全屏下可能不可见；无边框全屏正常。
6. **自动宽度是估算值**。按字体字号和字符宽度估算并保留安全余量；
   极长设备名会达到 1400 px 上限并在文本末尾省略。
7. **高缩放会抬高最小高度**。缩放 160% 时最低高度约 33 px；如需更矮，
   请先降低缩放或关闭进度线。
8. **任务栏模式只支持主屏水平任务栏**。竖向任务栏、自动隐藏、副屏任务栏或没有
   足够空白时会回退到底部贴边。

## 与 ClassIsland 的差异

参考 ClassIsland 的实现做产品对比（调研原文属于内部资料）。ClassIsland 普通模式
整窗点击穿透，并用全局 RawInput 检测悬停；Luma 采用更简单的 33ms 光标轮询，
避免引入 RawInput 与额外的窗口消息处理。

- ClassIsland 悬停时把不透明度降到 0.05；Luma 选择淡出到 0 后隐藏，彻底让出下方内容。
- ClassIsland 提供置顶/置底与 6 个停靠位置；Luma 是顶部/底部 + 左/中/右对齐，
  任务栏模式则自动贴近图标区。
- ClassIsland 可在设置里选择屏幕索引；Luma 目前是主屏 / 鼠标所在屏。
